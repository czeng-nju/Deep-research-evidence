# v0.3.0 评分导向优化报告（公开整理版）

本报告将优化逐条对应用户提供的 16 个评分细项。权重不是已获得的分数，没有官方成绩或保证提分。Skill 本体与已测试的 v0.3.0 完全一致；公开整理只补充说明、最小示例及可携带的测试证据。未向 Bohrium 提交。

## 新题对照结果

A=无 Skill，B=0.2.1，C=0.3.0。三个新合成任务，每组每题一次，9 次全部交付。输入、评分参考与实现先冻结再运行；新上下文独立研究，匿名模型审阅全部要求、事实和 90 条引用。具体来源与导出哈希见 [证据出处](../evidence/provenance.json)。

| 指标 | A | B | C |
|---|---:|---:|---:|
| 科学可答要求完整且正确 | 13/14 | 13/14 | 14/14 |
| 正确未知 | 6/6 | 6/6 | 6/6 |
| 六类交付内容完整 | 17/18 | 17/18 | 18/18 |
| 有效定位／实际前提贡献 | 31/31 | 30/30 | 29/29 |
| 单来源支持整个附带表述 | 26/31 | 27/30 | 28/29 |
| 范围限定问题 | 1 | 1 | 0 |
| 最终文件写出耗时中位数 | 243.6 秒 | 414.7 秒 | 428.8 秒 |

A、B 的局部引用将“没有证据表明被撤回／覆盖”改为确定的“未被撤回／覆盖”，因此一个要求只被评为部分正确；不是漏答整题，三组核心计算和冲突保留都正确。六类交付中的证据回链项也受同一措辞问题影响，不能当作两个独立改善。跨来源推断允许单条来源只提供一个前提，不能把所有 partial 引用都称为科学错误。

**效果观察主要对应结果正确性、质量增益及回链内容精度。** 新增要求与六项检查提供抗遗漏机制，但没有证明基础 Agent 不会拆解、检索或综合。范围标签仍需真实阅读，程序不会认证语义。

**效率增益目前仅有局部证据。** 5 次等价记账命令可合并为 1 次，保留全部逻辑操作和恢复记录；但 C 从派发到最终文件写出的三题合计耗时 1,369.5 秒，B 为 1,209.2 秒，增加约 13.3%，且三题逐项都更慢。这不是全部验证结束时间，也不是纯模型延迟。未证明整体提速、原生请求或 token 成本下降。

**可靠性有确定性测试支持。** 89 项脚本回归通过：原有 48、批处理 11、范围与交付审计 30。三组 S3 均真实执行本地模拟的空搜索改写、429 重试和解析回退，各 9 次服务调用；原始运行中的产物核验通过。公开目录保留摘要，不发布完整个人工作区，因此不能从公开摘要独立重演原始全部工具轨迹。

## 复跑和后续优先级

从仓库根运行 `python3 -m unittest discover -s tests -v`、`python3 skill/scripts/validate.py package --path skill`、`python3 scripts/check_release.py`。按最小示例启动实际 Agent，不要把示意输出或评测结果复制成新答案。

后续优先补真实文献核验（结果正确性／质量增益），压缩完整研究中的维护成本（效率增益），再做组件消融和已有方法公平比较（创新证据）。这些是尚缺的评分证据，不将新增功能直接折算为官方分数。
