# Research record

This is a blank recording template, not a research result. Populate only from the current task and actual actions. The requested output contract takes precedence.

## Scope and original requirements

Record case identity, question, objects, comparators, outcomes, time, allowed sources, inclusion/exclusion rules, input versions, assumptions and unavailable inputs. Assign stable requirement IDs before inspecting answers.

## Tool and artifact records

Link actual events and retained artifacts. Include failures and retry decisions; distinguish original files, parsed text, summaries and calculated results. If only part of the native trace is visible, state coverage.

## Conflict, uncertainty and gaps

For each material disagreement, compare population/system, design, intervention, comparator, endpoint, units and time. Record both sides and the unresolved reason. Link every gap to the searched scope and actual queries; distinguish absent evidence from inaccessible material.

## Delivery check

Report six aspects separately: decomposition, retrieval coverage, evidence links, conflict assessment, synthesis and bounded gaps. Distinguish requirements merely assigned a status from those substantively answered. State which structural checks and semantic reviews actually ran, and which remain unverified.
