# 合成对照的公开证据副本

这些文件是 v0.3.0 优化时已完成的合成测试材料，**不是给平台执行正式案例的预制答案**，也不是最小调用示例。可加载 Skill 和安装包都不包含此目录。执行任何新任务时不能读取 results、reviews 或评分参考作为答案。

条件 A 为不加载 Skill，B 为 0.2.1，C 为 0.3.0。S1 检查条件与多个终点，S2 检查版本和真正冲突，S3 运行本地模拟服务故障。9 次尝试全部完成；原始完整工作区、宿主轨迹和旧版 Skill 未随本发布目录导出。

- `cases/`：逐字保留的运行输入。S1/S2 的原文就在 materials；S3 的 service.py 按 tool-interface 执行，状态必须为每次新运行单独创建。
- `references/`：评分参考；S3/source-texts 是模拟解析后的参考文本，S1/S2 原文使用 cases 对应 materials。
- `results/A|B|C/`：实际试验最终输出，供核对；不是新的运行输出。
- `reviews/A|B|C/`：独立模型逐条评审。匿名候选 ID 保留；公开目录按条件解盲。
- `summary.json`、`timing.csv`：描述性汇总与观测计时。摘要中原始日志哈希／路径只是历史出处，原日志未在公开目录中提供，不应将其当作可直接打开的文件。
- `REVIEW_PROTOCOL.md`：原始审阅规则，供理解方法；原位执行工具及工作目录未全量导出。

[出处与双哈希清单](../evidence/provenance.json) 标明每个导出文件的本地原始相对路径、原始哈希、发布哈希以及是否删除作者绝对路径。原始数据没有被回写。公开副本能用于检查答案、引用、参考和描述性指标；它不是完整原始工作区镜像，不能承诺原位重放全部工具事件。所有科学资料均为合成，不冒充真实论文。

若要再次对照，请在新的独立上下文中只分发对应 cases 输入和指定 Skill，使用相同工具与预算，保存所有尝试；先不要向研究 Agent 暴露评分参考、results 或 reviews。这些题已经公开，不能再称为未见保留集。最小真实调用见 [示例说明](../examples/minimal/README.md)。
